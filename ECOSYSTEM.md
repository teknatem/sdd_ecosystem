# Экосистема SDD

Четыре репозитория в `F:\dev`. Три из них — приложения, четвёртый — этот канон.

```
F:\dev\
  sdd_ecosystem\ канон: имена, метод, схема манифеста, контракты. Кода нет
  sdd_mpi_app\   Integrator (MPI) — приложение, построенное по SDD
  sdd_studio\    SDD Studio — анализатор SDD-проектов
  sdd_desktop\   SDD Desktop — тонкий клиент к SDD-приложению
```

## Кто есть кто

| Репо | Что это | Стек | Роль в экосистеме |
|---|---|---|---|
| `sdd_mpi_app` | **Integrator (MPI)** — учёт и стыковка 1С:УТ 11 с WB / Ozon / Яндекс Маркет | Rust, Axum + Leptos/WASM, SQLite | Приложение. Референсная реализация метода: его `architecture.toml` — первый живой манифест SDD |
| `sdd_studio` | **SDD Studio** — просмотр, анализ и диагностика структуры SDD-проекта | Rust, egui | Инструмент. Читает манифест приложения, строит дерево объектов, сцену и findings |
| `sdd_desktop` | **SDD Desktop** — десктоп-оболочка, грузящая фронт приложения с выбранного сервера | Tauri v2 | Клиент. О внутренностях приложения не знает ничего, кроме URL |
| `sdd_ecosystem` | Канон | — | Не приложение. Ни от кого не зависит и ни на кого не ссылается, кроме этой таблицы |

Приставка `sdd_` в имени каталога означает «принадлежит экосистеме», а не
«инструмент SDD». Полное правило имён — в [GLOSSARY.md](GLOSSARY.md).

## Карта связей

```
     sdd_ecosystem  (канон — читают все, не читает никого)
         ^                ^                    ^
         |                |                    |
   sdd_mpi_app  <--(1)(2)--  sdd_studio    sdd_desktop
         ^                                     |
         +-------------------(3)---------------+
```

1. **Studio читает манифест приложения** — `architecture.toml` из корня.
2. **Studio пишет артефакты анализа в приложение**, приложение забирает из них метрику.
3. **Desktop грузит фронт приложения по HTTP** из профиля подключения.

Всё. Других связей нет и заводить их нельзя — детали и границы каждого стыка в
[CONTRACTS.md](CONTRACTS.md).

## Что каждый репозиторий обязан знать о соседях

Ровно один абзац «моё место в экосистеме» в своём `README.md` со ссылкой на этот
файл. Не копию таблицы — ссылку.

Прямо запрещено: читать `memory-bank/`, `docs/` или исходники соседнего репо.
Единственный разрешённый кросс-репо линк — на `F:\dev\sdd_ecosystem\*`. Это не
гигиена, а защита контекста: агент, которому дали три memory-bank сразу, тратит окно
на чужие подробности и путает термины соседних доменов.
