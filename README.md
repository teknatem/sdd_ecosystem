# SDD — канон экосистемы

Это репозиторий **без кода**. Здесь лежит то, что обязано быть написано ровно один
раз: имена, метод, схема манифеста и список разрешённых стыков между приложениями.

Причина существования — та же, по которой в приложении появился
`architecture.toml`: правила, размноженные по репозиториям, расходятся молча. До
2026-08-18 канон имён жил внутри `sdd_studio/memory-bank/`, и `sdd_desktop` ходил
за ним в чужой memory-bank по относительному пути. Studio — один из потребителей
канона, а не его владелец.

## Правило чтения

Канон **не знает ни об одном конкретном приложении**. Он описывает метод; какие
приложения по нему построены — сведения из `ECOSYSTEM.md`, и это единственный файл
здесь, где вообще упоминаются имена репозиториев.

Обратное правило важнее: приложение не копирует канон к себе. Оно держит одну
ссылку сюда. Копия — это будущее расхождение, и мы уже знаем, чем оно кончается
(см. `SDD.md`, раздел «Почему манифест исполняется»).
