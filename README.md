# SDD — канон экосистемы

**Редакция 1.0.0** ([CHANGELOG.md](CHANGELOG.md)). Потребитель объявляет у себя,
под какую редакцию он выровнен: `[meta] canon_version` в его `architecture.toml`.

Это репозиторий **почти без кода**. Здесь лежит то, что обязано быть написано ровно
один раз: имена, метод, схема манифеста и список разрешённых стыков между
приложениями. Единственный исполняемый файл — проверка самого канона.

Причина существования — та же, по которой в приложении появился
`architecture.toml`: правила, размноженные по репозиториям, расходятся молча. До
2026-08-18 канон имён жил внутри `sdd_studio/memory-bank/`, и `sdd_desktop` ходил
за ним в чужой memory-bank по относительному пути. Studio — один из потребителей
канона, а не его владелец.

## Канон проверяется машиной

`SDD.md` требует от приложения, чтобы его стандарт исполнялся валидатором:
непроверяемый стандарт дрейфует и становится хуже отсутствия стандарта, потому что
всё ещё выглядит авторитетно. Канон подчиняется собственному требованию —
`check_canon.ps1` ловит висячие ссылки, несуществующие пути, участников без origin,
остатки прежних имён и потребителей, выровненных не под ту редакцию:

```powershell
.\check_canon.ps1
```

Требование это не теоретическое. Первая же редакция канона за один день успела
объявить, что у Studio и Desktop нет remote (был у обоих), и перечислить 4 файла
артефактов из 7 реально существующих.

## Правило чтения

Канон **не знает ни об одном конкретном приложении**. Он описывает метод; какие
приложения по нему построены — сведения из `ECOSYSTEM.md`, и это единственный файл
здесь, где вообще упоминаются имена репозиториев.

Обратное правило важнее: приложение не копирует канон к себе. Оно держит одну
ссылку сюда. Копия — это будущее расхождение, и мы уже знаем, чем оно кончается
(см. `SDD.md`, раздел «Почему манифест исполняется»).

Это же правило действует **внутри** канона: один факт живёт в одном файле,
остальные ссылаются. Статусы слоёв объявлены в `SDD.md`, семейства индексов — там
же, открытые долги — в `DEBT.md`. Второй копии не заводить, даже удобной.
